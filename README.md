# 🏗️ Obras e Reformas BH

Um site dedicado a conectar proprietários de imóveis em Belo Horizonte com profissionais especializados em obras e reformas.

## 📋 Sobre o Projeto

**Obras e Reformas BH** é uma plataforma online que facilita a busca e contratação de serviços de construção e reforma em Belo Horizonte. O site oferece uma ampla gama de serviços, desde reformas residenciais até consertos domésticos de emergência.

## ✨ Funcionalidades Principais

- **Catálogo de Serviços**: Navegue por diversos tipos de serviços oferecidos (portões, reformas, prevenção de acidentes, etc.)
- **Profissionais Cadastrados**: Visualize perfis de profissionais especializados
- **Regiões Atendidas**: Confira quais regiões de BH são atendidas
- **Blog Informativo**: Artigos úteis sobre obras e reformas
- **Formulário de Contato**: Entre em contato facilmente com os prestadores de serviço
- **Otimização SEO**: Site otimizado para buscadores

## 📁 Estrutura do Projeto

```
obrasereformasbh.com/
├── index.html                          # Página inicial
├── main.css                            # Estilos principais
├── super-lazy-load.js                  # Script para carregamento lazy de imagens
├── gtag_config.js                      # Configuração Google Analytics
├── robots.txt                          # Arquivo para buscadores
├── sitemap-obrasereformasbh.xml        # Mapa do site
├── site.webmanifest                    # Manifesto PWA
├── CNAME                               # Configuração de domínio customizado
│
├── servicos/                           # Serviços disponíveis
├── profissionais/                      # Perfis dos profissionais
├── quem-somos/                         # Página sobre a empresa
├── blog/                               # Artigos do blog
├── contato/                            # Formulário de contato
├── regioes-atendidas/                  # Áreas de cobertura
├── portao-basculante-ou-de-correr/    # Serviço específico
├── acidentes-domesticos/               # Prevenção de acidentes
├── components/                         # Componentes reutilizáveis
├── assets/                             # Imagens e recursos
└── termos-de-uso-e-politica-de-privacidade/ # Documentos legais
```

## 🚀 Como Usar

### Localmente

1. **Clone o repositório**:
   ```bash
   git clone https://github.com/igoraujo/obrasereformasbh.com.git
   cd obrasereformasbh.com
   ```

2. **Abra no navegador**:
   - Abra o arquivo `index.html` diretamente no seu navegador
   - Ou use um servidor local (exemplo: Live Server no VSCode)

### Deploy

O site é automaticamente deployado via GitHub Pages quando há push para a branch `main`.

- **URL**: obrasereformasbh.com
- **Branch**: main
- **Configuração**: GitHub Pages habilitado
